PEMROGRAMAN WEB 2 - PERTEMUAN 5
BAB IV - MANIPULASI BERKAS

ISI:
1. test1.txt
   File teks yang digunakan pada Latihan 1.

2. fgets1.php
   Latihan 2, membaca satu baris pertama menggunakan fgets().

3. fgets2.php
   Latihan 3, membaca seluruh isi file menggunakan while dan feof().

4. counter.php
   Latihan 4, membuat counter pengunjung menggunakan file counter.dat.

CARA MENJALANKAN:
1. Aktifkan Apache pada XAMPP.
2. Letakkan folder PERTEMUAN_05 di:
   C:\xampp\htdocs\
3. Buka browser:
   http://localhost/PERTEMUAN_05/fgets1.php
   http://localhost/PERTEMUAN_05/fgets2.php
   http://localhost/PERTEMUAN_05/counter.php

CATATAN:
- counter.dat akan dibuat otomatis setelah counter.php dijalankan.
- Untuk mengulang counter dari angka 1, hapus file counter.dat.
